# Feature: first-blood bonus

**Type:** feature request · **Reported by:** event organizer · **Area:** scoring

## Context

We want to reward the first team that solves each challenge ("first blood") with extra points. It needs to feel
like part of the score, not a separate leaderboard.

## Requirements

- **R5.1** A "First Blood Bonus" setting (points; empty or 0 = disabled) in Admin Panel → Config, in the Accounts
  section next to the other submission settings. It is stored as the config key `first_blood_bonus`, so it can also
  be set through the existing configs API (`PATCH /api/v1/configs`). Only admins can change it.
- **R5.2** When the bonus is enabled, the first account (the team, in teams mode) to solve a challenge receives the
  bonus once for that challenge, and nobody else does. The team sees it as its own line item named
  `First blood: <challenge name>` on its team page.
- **R5.3** The bonus counts everywhere points count: the scoreboard (page, API and the score graph of the top
  teams), the team's score and place, and the score of the member who solved it.
- **R5.4** Exactly one first blood per challenge, even when several teams submit the correct flag at the same moment;
  it goes to the team whose solve was recorded first. A team racing with itself (several members at once) still
  gets one bonus.
- **R5.5** Hidden or banned accounts (e.g. our staff test team) never take first blood; the first visible solver gets
  it.
- **R5.6** The amount is the setting at the time of the solve: changing the setting later does not change bonuses
  already given, and enabling it later does not pay challenges that were already solved.
- **R5.7** Works for every challenge type (standard and dynamic).
