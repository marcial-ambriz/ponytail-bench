# Feature: wrong-answer penalties

**Type:** feature request · **Reported by:** event organizer · **Area:** challenges, scoring

## Context

Some teams brute-force flags by guessing. We want to make wrong answers cost something on selected challenges,
without making the scoreboard look broken.

## Requirements

- **R3.1** Each challenge has a `penalty`: a whole number of points, 0 by default (0 = no penalty). Admins set it
  when creating or editing a challenge, both in the admin panel (create and edit forms; the edit form shows the
  current value) and through the challenges API (`POST /api/v1/challenges`, `PATCH /api/v1/challenges/<id>`; numeric
  strings from the admin forms are accepted). `GET /api/v1/challenges/<id>` returns `penalty`, also to players.
  Works for every challenge type (standard and dynamic).
- **R3.2** Every wrong answer on a challenge with a penalty deducts that many points from the account's score (the
  team's score in teams mode). The deduction shows wherever the score shows (team page, team API, scoreboard).
- **R3.3** Never charged twice: submitting the same wrong answer again to the same challenge costs nothing extra,
  whoever on the team sends it, with or without surrounding spaces, and even when the copies arrive at the same
  moment (double clicks, two teammates).
- **R3.4** A score never goes below zero because of penalties: a deduction is capped at the team's current score, and
  a team with no points is not charged. This must also hold when several wrong answers arrive at the same moment.
  Penalties never delete or change earlier solves or awards.
- **R3.5** No penalty for correct answers, for answers to a challenge the team already solved, for submissions
  rejected by rate limiting, or on challenges whose penalty is 0.
- **R3.6** Each deduction is visible to the team as its own line item named `Penalty: <challenge name>` on the team
  page (public `/teams/<id>` and own `/team`).
- **R3.7** Players are warned before they submit: the challenge window states the penalty (the word "penalty" and
  the number of points). Challenges without a penalty show no such text.
- **R3.8** Invalid penalties (negative, fractional, non-numeric, booleans) are rejected with HTTP 400 and the
  challenge is not created or not changed.
- **R3.9** Changing a challenge's penalty only affects later wrong answers; past deductions stay as they were.
- **R3.10** Only admins can set penalties.
